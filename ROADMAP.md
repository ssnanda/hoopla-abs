# Development roadmap

## 0.1 — Local working foundation (this starter)
- macOS (Intel + Apple Silicon) command-line launcher.
- Hoopla public book-link validation and optional public metadata retrieval.
- Local DRM-free MP3/M4A/etc. to chaptered M4B with FFmpeg.
- Synthetic-audio sample, inspection, tests, no Hoopla credentials.

## 0.2 — Improved library manager
- Save searchable public book metadata records and track borrowed/returned dates locally.
- Resumable *local* conversion queue and duplicate detection.
- Better chapters, cover and narrator metadata imported from locally owned/authorized sources.

## 0.3 — Optional macOS Swift interface
- Simple Paste Link / Book Info / Import Local Audio / Package screens.
- Progress and clear errors; no embedded credentials.

## Out of scope without authorization
- Hoopla loan downloading, recording, reverse-engineered private endpoints, license circumvention, DRM bypass.

## Later optional integration
- Audiobookshelf import, only when the local packaging workflow is proven and explicitly requested.
